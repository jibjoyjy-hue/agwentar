# Gwentar

เว็บแอปดูแลใจสำหรับเด็กและวัยรุ่นอายุ 10–18 ปี เปิด `index.html` ได้เลย ไม่ต้อง build

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ (HTML ของทุกหน้าจอ)
css/                  สไตล์ แยกตามส่วน โหลดตามลำดับเลขหน้าชื่อไฟล์
  01-base.css         ตัวแปรสี ฟอนต์ ธีม
  02-layout.css       โครงหน้าแอป แถบหัว
  03-pet.css          ตัวสัตว์เลี้ยง
  04-…16-*.css        แต่ละหน้าจอ (ชื่อไฟล์บอกหน้าจอ)
  17-responsive.css   ปรับขนาดมือถือ / iPad / คอม (ต้องโหลดท้ายสุด)
js/
  data/               ข้อมูลชุดและตัวสัตว์เลี้ยง
  features/           premium.js (สมาชิก), safety.js (หน้าขอความช่วยเหลือ ตรวจคำเสี่ยง)
  core/               state, ภาษา, บันทึกข้อมูล, เปลี่ยนหน้า, syncUI, ผูกปุ่ม, เรียก AI
  pets/               หน้าตา ท่าทาง การดูแลสัตว์เลี้ยง
  screens/            โค้ดของแต่ละหน้าจอ
  games/              มินิเกมแต่ละเกม
assets/  audio/       รูปและเสียง
ai-proxy/             Cloudflare Worker สำหรับคุยกับ AI
```

## กติกาเวลาแก้

- ไฟล์ JS เป็นสคริปต์ธรรมดา (ไม่ใช่ module) ทุกไฟล์ใช้ตัวแปรและฟังก์ชันร่วมกันได้
  ห้ามเรียกฟังก์ชันจากไฟล์อื่น **ตอนโหลดไฟล์** ให้เรียกในฟังก์ชันหรือหลัง `DOMContentLoaded` เท่านั้น
- เพิ่มไฟล์ใหม่ต้องเพิ่ม `<script>` หรือ `<link>` ใน `index.html` ด้วย
- แก้แล้วให้เพิ่มเลข `?v=` ในไฟล์ที่แก้ใน `index.html` เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
- ลำดับไฟล์ CSS มีผล ไฟล์หลังทับไฟล์ก่อน
- รายการคำเสี่ยงอยู่ 2 ที่ ต้องแก้ให้ตรงกัน: `js/features/safety.js` และ `ai-proxy/worker.js`
- `premium_codes.html` เป็นหน้าแอดมิน อยู่ใน `.gitignore` ห้ามอัปขึ้นเว็บ
